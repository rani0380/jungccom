# 나의 임용 공부방

전공 모의고사와 교육학 기출을 직접 열어 답안을 작성하고 복습하는 개인 학습 사이트입니다.

## 사용 방법

1. 전공 모의고사 / 교육학 기출에서 원하는 시험을 선택합니다.
2. 화면에 안내된 PDF 파일을 선택합니다. ZIP은 기기에서 먼저 압축을 해제하세요.
3. 답안을 작성합니다. 모범답안·강의노트 확인을 눌러 해당 PDF를 선택합니다.
4. 헷갈린 개념을 적고 다시 보기 또는 복습 완료로 표시합니다.

교재 원문, 스캔 이미지, 모범답안 PDF는 저장소 및 배포 결과에 포함하지 않습니다. 선택한 PDF는 브라우저 IndexedDB에만 보관되고 서버에 업로드되지 않습니다. 브라우저 데이터를 지우거나 다른 기기로 이동하면 파일을 다시 선택해야 합니다.

## 저장과 동기화

- Supabase 미설정 또는 로그아웃: 이 기기의 임시 초안에만 저장됩니다.
- Supabase 설정 후 로그인: 사용자별 답안·메모·복습 상태가 동기화됩니다.
- PDF 자체는 동기화하지 않습니다.
- 동일한 문제지 쪽을 두 기기에서 동시에 수정하면 마지막 저장이 반영됩니다.
- 로그인 전 임시 초안과 로그인한 계정의 기록은 분리됩니다. 필요한 초안은 복사 후 로그인하세요.

자동 동기화 설정은 [SETUP.md](SETUP.md)를 참고하세요. 제공된 답안과 직접 비교하는 방식이며 자동 채점 기능은 없습니다.

## 자료 구성

- 2027 대비 전공 1·2·3회 A/B형과 추석 번외 A형
- 교육학 모범답안집에 수록된 2014~2026학년도 문제와 해당 답안 쪽
- 2014·2015의 두 번째 수록 자료는 출처 구분을 보존하기 위해 '자료 2'로 표시

문제 페이지 인덱스와 파일명만 포함되어 있습니다. 원본의 권리는 각 저작권자에게 있습니다.

## 개발

Node.js 22.13 이상에서 `npm ci`, `npm run dev`를 실행하세요. `npm run build` 결과는 `dist/`에 생성됩니다. GitHub Actions가 main 브랜치의 변경을 Pages로 배포합니다.
